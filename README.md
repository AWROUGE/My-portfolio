# Minimal Link Manager

A simple personal link page made with HTML,CSS and JS.

## Edit your links

Open `script.js` and change the `links` array:

```js
const links = [
  {
    name: "github",
    label: "github.com/yourusername",
    url: "https://github.com/yourusername"
  }
];
```

You can add as many links as you want.

## Customize your profile

Open `index.html` and change:

- `"Ahmed Almsleh"`
- The short bio
- The Github account avatar

## Run it

You can simply open `index.html` in a browser.

For publishing, upload the three files to a GitHub repository and enable GitHub Pages, or deploy the folder with a static hosting service.
